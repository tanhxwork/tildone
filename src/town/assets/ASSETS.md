# Town sprite assets

All sprites here are from **Kenney "Tiny Dungeon" (1.0)** — https://kenney.nl/assets/tiny-dungeon
Licensed **CC0 1.0 Universal** (public domain): free to use, modify, and
redistribute, including in this public repo. Full text in `Kenney-License.txt`.

Selected 16×16 tiles (original Tiny Dungeon index → our name):

- 48 → `floor.png`, 49 → `floor2.png` (room floor)
- 58 → `wall.png` (room wall strip)
- 72 → `desk.png` (the desk a character works at)
- 46 → `door.png`
- Characters — one distinct person per agent identity:
  - 109 → `char-claude.png`
  - 112 → `char-codex.png`
  - 84 → `char-cursor.png`
  - 99 → `char-secretary.png`
  - 97 → `char-generic.png` (unknown / fallback agent)

If you add sprites from another pack, record its license here and keep every
shipped asset CC0 — this repo is public.
